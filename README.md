# Expense Tracker CLI 
A CLI expense tracker built using Python and MySQL. Add, view and delete expenses with monthly summaries and category filtering.

## Features 
- Add expenses with amount, description, category and date.
- View all expenses incurred.
- Generate monthly summary reports by category.
- Delete expenses by ID.
- Persistent storage using MySQL database.
- Categories pre-loaded: Food, Transport, Entertainment, Bills, Shopping, Health, Other.
